# Invoker Lab

A static browser-based Invoker practice game. Use Q, W, and E to load orbs, press R to invoke the matching spell, and use D/F to cast the two invoked spells. It includes all ten Invoker spells, a training dummy, damage feedback, and keyboard controls.

- Play: https://jhon-guiller-barenio-portfiolio-v2.vercel.app/projects/invoker-lab/
- Portfolio: https://jhon-guiller-barenio-portfiolio-v2.vercel.app/

This is a fan-made practice simulator and is not affiliated with Valve or Dota 2. It does not reproduce the full Dota 2 game engine.

The app is self-contained in index.html and can be run locally by opening that file in a browser or serving the folder with any static web server.
